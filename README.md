## Intégration du template Electro

Les assets du template `Electro-Bootstrap-1.0.0` sont copiés partiellement dans `public/theme/`.

Pour tester localement (PHP built-in server depuis le dossier `public`):

```bash
cd public
php -S localhost:8000
```

Puis ouvrir `http://localhost:8000`.
